## About

I work broadly on **model-based systems engineering (MBSE)**, **system-level modeling and simulation**, and **safety & reliability engineering**.

My current work involves **SysML v2**, **Modelica/OpenModelica**, simulation-driven engineering, safety analysis, and AI-assisted modeling workflows.

## Current Open-Source Work

### [modelica-system-level-simulation-skill](https://github.com/Ruizhe-Yang/modelica-system-level-simulation-skill)
An OpenModelica-first Agent Skill for system-level Modelica modeling, diagnosis, visualization, validation, and optimization.

### [SafetyAssessmentLibrary](https://github.com/Ruizhe-Yang/SafetyAssessmentLibrary)
A Modelica library for independent, simulation-driven dynamic safety assessment.

### [FaultReplacementLibrary](https://github.com/Ruizhe-Yang/FaultReplacementLibrary)
A Modelica library for non-intrusive, component-replacement-based fault injection and fault-effect simulation.
